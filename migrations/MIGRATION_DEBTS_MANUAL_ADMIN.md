# Миграция: ручные долги — корректировка и погашение (API)

**Дата:** 2026-04-18

## Суть изменений

- Добавлены эндпоинты:
  - `PATCH /api/reports/debts/manual/{id}` — корректировка ручной записи долга (сумма, причина, точка, период, заказ, комментарий).
  - `POST /api/reports/debts/manual/{id}/settle` — полное погашение: сумма записи приводится к уже зачтённому в «Взято»; при отсутствии зачётов запись удаляется.
- Фронт: страница «Долги и Взято» (`/reports/debts-summary`) — кнопки «Погасить полностью», «Корректировка», «Удалить» (как раньше — удаление только без зачётов).

## База данных

**Изменений схемы не требуется.** Используется существующая таблица `manual_employee_debts` (модель `ManualEmployeeDebt`).

Отдельный SQL-скрипт или `migrate_*.py` для этого релиза **не нужен**.

## Деплой

1. Обновить код бэкенда и фронтенда на сервере.
2. Перезапустить API:

   ```bash
   sudo systemctl restart crm-backend
   ```

3. Собрать и выложить статику фронта (из корня репозитория):

   ```bash
   bash /home/deploy.sh
   ```

4. Проверить: `https://mosoptika-study.ru/reports/debts-summary` (админ), вкладка «Долги».

## Откат

- Откат кода бэкенда/фронта к предыдущему коммиту; перезапуск `crm-backend` и повторный `deploy.sh` при необходимости.
- Данные в БД при использовании новых API меняются осмысленно (суммы/удаление записей); откат кода **не откатывает** уже выполненные правки в `manual_employee_debts`.
